# Format playbook

Data: novitckii.com/resources/viral-carousels (10,743 Instagram carousels). "Doubled" means at least 2x the creator's usual engagement; the baseline is 23.9%. The evidence is correlational and Instagram-based. Treat it as a strong prior for LinkedIn, not a law.

| Format | Doubled | Use when |
|---|---|---|
| Cheat sheet / reference | 37.5% | the source has steps, rules or definitions worth saving |
| List ("N ideas") | 26.1% | default for most articles |
| How-to | 25.1% | the source teaches a process |
| Opinion | 24.5% | there is a hot take or tension |
| Story | 23.3% | there is a narrative case |
| News / showcase | 18.7% / 18.2% | avoid: reframe as "what this means for you" plus steps |

Aim for something people save or send.

## Slide count
Default 9. Sweet spot 8-12 (up to 15 works). Never 3 or fewer. Past 15, completion declines.

## Skeleton

| # | Role | Pattern |
|---|---|---|
| 1 | Cover | kicker + hook headline + "N ideas" numeral + hero visual or mascot |
| 2..N-1 | One idea each | numeral, 2-line headline with one accent word, 1-2 blocks (h3 up to 4 words, p up to 2 lines), ONE visual |
| N | Close | thesis line, one save/send CTA, source credit |

## Per-format hints
- **Cheat sheet**: each slide is a rule plus a one-line example; the last slide recaps the rules as a list.
- **List**: one idea per slide, ordered by strength, strongest second or last.
- **How-to**: step numerals, each step starts with a verb, finish with a "common mistake" slide.
- **Opinion**: slide 2 states the claim, middle slides give evidence, one slide steelmans the other side.
- **Story**: setup, tension, turn, lesson; keep names and numbers.
