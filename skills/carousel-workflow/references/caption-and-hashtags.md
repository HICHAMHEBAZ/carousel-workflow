# Caption and hashtags

Write `caption.md` next to the PDF on every run, one block per platform. Same register as the slides; Darija flavour only if the user asked.

## Formula
Length: 120-250 words (30.3% of posts doubled against 25.3% outside that range). The carousel hooks; the caption adds context and one next step. No link and no "link in bio" (19.4% against 26.5%). Credit the source by name only.

1. **Hook line** (at most 12 words): the cover question or the boldest tension, one emoji at most.
2. **Context paragraph** (2-4 short sentences): why this matters now, what the source adds, what the reader gains.
3. **3 takeaways** as bullets, at most 14 words each, one per key slide. No slide numbers.
4. **Save ask**: one line asking to save the post (posts with a save ask doubled 32.8% against 24.9%).
5. **Source credit**: `Source: <Author>, <Outlet> (<year>)`, translated into the post language.
6. **Comment driver**: one open question asking for a choice or an opinion.
7. **Hashtags** on their own line.

Keep the save ask and the question as the only calls to action.

## Hashtag counts
- LinkedIn: 3-5 · Instagram: 10-15 · X / Threads: 1-2
- Mix: 1-2 broad (topic), 1-2 niche (angle), 1 local, plus native-language tags on Instagram.
- Never use engagement-bait tags (#follow4follow, #viral, #explore, #fyp).
- Hashtags help a niche reach the post; they do not make it viral. Say so if asked for "viral" tags.

## Template
```markdown
# Caption - <title>
Direction: <palette / design direction used>

## LinkedIn
<hook>

<context paragraph>

• <takeaway 1>
• <takeaway 2>
• <takeaway 3>

<save ask>
<source credit>
<question>

<3-5 hashtags>

## Instagram (only if requested)
<same caption>

<10-15 hashtags>

## X / Threads (only if requested)
<hook> <1-2 hashtags>
```

## Posting tips for the reply
- Post Tuesday-Thursday, 8-10am in the audience's time zone.
- Reply to every comment in the first hour.
- Tag 2-3 people who would genuinely have an opinion; do not mass-tag.
